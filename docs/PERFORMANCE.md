## 复现

源码基线用 `git show v0.1.1:index.js` 导出，候选使用当前 index.js，宿主使用同一个 Aide plugin_host.js。将三者与脚本放进正在运行的 Aide 容器，再执行：

```sh
node benchmark_snapshot.cjs \
  --legacy /tmp/legacy.js \
  --plugin /tmp/index.js \
  --host /tmp/plugin_host.js \
  --output /tmp/report.json \
  --rounds 9
```

脚本读取当前工作区快照，在仅监听 127.0.0.1 的 HTTPS 服务中固定回放；证书校验保持开启，令牌只在进程内。脚本不调用模型，不修改源文件或索引策略，结束时清理自己的临时宿主文件。报告仅含计数、摘要、计时和对照结果，不公开索引正文。
